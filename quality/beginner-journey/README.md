# UX-PATH-001 初学者向け学習導線

## 目的

公開中の教材を「全レッスンの一覧」ではなく、初学者が現在地と次の一手を判断できる一本道として提示する。教材ID、共有URL、保存済み進捗は維持する。

## 対象と公開範囲

- 対象: Rとプログラミングを初めて学ぶ人
- 公開範囲: Rの基礎、R / RStudioの環境構築、実機でのFoundation Check、STEP 1のデータ操作
- 未公開: 可視化、ベイズ統計、brms、Stan
- 初回体験: インストール不要、5〜10分

未公開内容を完了後の主導線として案内しない。公開範囲を修了した後は、STEP 1の復習、演習ノートの再利用、公開予定の確認だけを実行可能な選択肢として示す。

## 状態遷移

| 順序 | 段階 | 完了条件 | 次の対象 |
|---|---|---|---|
| 1 | 体験 | L1の理解問題を完了 | STEP 0 |
| 2 | STEP 0 | L10の理解問題を完了 | R基礎 |
| 3 | R基礎 | L2〜L9の理解問題を完了 | Foundation Check |
| 4 | Foundation Check | L10に定義した実機5項目を確認 | STEP 1 |
| 5 | STEP 1 | L11〜L16の理解問題とL16の成果物4項目を確認 | 公開中トラック修了 |

L10の教材IDと進捗キーは互換性のため維持する。L10本文・理解問題はSTEP 0として早期に提示し、`practice.l10` は全R基礎後の独立したFoundation Check画面で提示する。

## レッスン内の反復順序

L1〜L16は、本文を読み終えた直後に次の4段階を1回ずつ行ってから理解問題へ進む。

| 段階 | 学習者の行動 | 支援の減らし方 |
|---|---|---|
| 1. まねる | 例を見ながら、そのままRで実行する | 完成例を利用できる |
| 2. ひとつ変える | 結果を予想してから値や条件を1か所変える | 構造は残す |
| 3. 見ずに作る | 例を閉じ、空のスクリプトから短いコードを再現する | 完成例を使わない |
| 4. 別の場面で使う | 名前・値・文脈を変えた小課題へ移す | 手順ではなく考え方を再利用する |

各段階は上から順に解除し、途中の段階を解除した場合は後続段階も未完了へ戻す。`drill`は実行したという自己記録であり、到達目標の直接証拠、理解済み、実践済み、観察ゲート通過には数えない。理解は直後の問題、実践はL10・L16の成果物、転移は所定の観察課題で別々に測る。

## 再開規則

1. 上表を先頭から評価する。
2. 最初の未完了段階を現在地とする。
3. レッスン段階では、段階内の最初の理解未完了レッスンを開く。
4. Foundation Checkでは専用URL `#/foundation-check` を開く。
5. STEP 1の理解問題が完了し、成果物チェックが残る場合はL16を開く。
6. 直接URLから後続段階へ入ることは妨げない。ただしFoundation Checkでは、前提未完了を明示する。

この規則では「最初の未完了番号」ではなく「最初の未完了学習段階」を再開点にする。理解問題と実機確認は別の進捗として扱う。

## 画面要件

ホーム画面は次の順に示す。

1. 対象、初回所要時間、公開範囲
2. 現在地、次にすること、単一の主ボタン
3. 公開中トラック全体の進捗
4. 5段階の学習経路
5. 折りたたんだ全レッスン一覧
6. 保存、読み込み、リセットなどの管理操作

内部の旧レッスン番号は主導線に使わず、「体験」「STEP 0」「R基礎 1 / 8」「STEP 1 1 / 6」のように学習上の意味を表示する。

## 互換性

- `l1`〜`l16`のIDを変更しない。
- `#/lesson/:id`を維持する。
- schema v3で`done`、`first`、`missed`、`practice`を維持し、4段階練習の自己記録を`drill`として追加する。schema v1・v2の保存データは既存進捗を失わず移行する。
- 新しいFoundation Check URLを追加するが、既存URLを無効化しない。
- 新規公開レッスンは、教材ファイルの追加だけでなく`JOURNEY_STAGES`への明示登録を必須とする。

## 受け入れ条件

- 新規読者に、準備不要の体験が唯一の主ボタンとして表示される。
- L1修了後の再開先はSTEP 0、STEP 0修了後はL2になる。
- L9の次はSTEP 1へ飛ばず、Foundation Checkになる。
- Foundation Check完了後はL11へ進む。
- L16の理解問題だけを終えても、成果物4項目が未完了なら公開中トラック修了とは表示しない。
- 全修了後の画面に、未公開コンテンツへ進むと誤認させる主ボタンがない。
- Foundation Checkだけを先に終えても、公開中トラック修了とは表示しない。
- 直接URL、ブラウザ履歴、保存済み進捗が動作する。
- キーボード操作と自動アクセシビリティ検査に重大な問題がない。

## 観察時の確認事項

初学者3名以上について、支援なしで次を確認する。

- 10秒以内に、現在の公開範囲と最初の行動を説明できる。
- 最初の体験にインストールが不要だと判断できる。
- L1後にSTEP 0へ、R基礎後にFoundation Checkへ、その後STEP 1へ進める。
- 「理解済み」と「実機確認済み」の違いを説明できる。
- 4段階を上から進め、例を閉じる段階と別文脈へ移す段階で、完成例へ戻らず試せる。
- 4段階のチェックが自己記録であり、理解済み判定とは別だと説明できる。
- CSVの読み込みから要約結果の再生成までを、支援水準付きで記録する。

L1–L10の結果はFoundation Gateの証拠として記録する。L12→L13の「読込成功と品質保証の区別」、raw保全、未見表への転移は[STEP 1 Data Quality Gate](../step1-data-gate/README.md)、L16修了後に別シナリオへ品質検査・集計・解釈を移す行動は[STEP 1独立転移観察キット](../step1-transfer-gate/README.md)で記録する。3〜5名の結果を一般化せず、導線上のP0・P1発見と次版の基準値作成に使う。
