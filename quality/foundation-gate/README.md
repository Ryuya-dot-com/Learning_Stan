# Foundation 公開後フィードバック

このディレクトリは、L1–L10の利用時に得られる実機アクセシビリティと初学者のフィードバックを、匿名化して次版の改善へ結び付けるための正本です。旧称はFoundation Gateでしたが、**公開・教材完成・品質判定を止めるゲートではありません**。

自動テストは実装の整合性を確認します。実機利用や少人数の感想は、テストからは分からない改善点を発見する補助的な根拠です。未実施であること、参加者が少ないこと、または実機構成がそろわないことを理由に公開を止めません。また、未実施の学習効果・アクセシビリティ適合・第三者検証を主張しません。

## 使用する文書

- [実機アクセシビリティ監査票](ACCESSIBILITY_AUDIT.md)
- [初学者フィードバック・プロトコル](LEARNER_OBSERVATION_PROTOCOL.md)
- [匿名フィードバック記録票](LEARNER_OBSERVATION_RECORD.md)
- [改善記録テンプレート](GATE_DECISION.md)
- [現在の機械可読状態](status.json)

状態は次のコマンドで確認できます。これは記録の形式を検査するだけで、未実施状態も終了コード0で報告します。

```bash
npm run gate:status
```

`status.json`は、記録済みの根拠、追跡中の改善項目、または未実施を区別します。全14分類を埋めること、参加者数、独立レビュー、実機構成をPASS条件にはしません。

記録を残す場合は、氏名、学籍番号、メールアドレス、成績、障害・診断情報、画面録画、音声、生のアクセスログを保存しません。正式な研究・発表へ転用する場合は、所属機関の倫理審査と同意要件を別途確認します。

```text
quality/foundation-gate/feedback/
└── FF-2026-08-13/
    ├── accessibility-windows-nvda.md
    ├── learner-P01.md
    └── improvement-notes.md
```

## 記録の読み方

- `NOT RUN`: まだフィードバックを記録していない
- `RECORDED`: 匿名化した根拠を記録した
- `NEEDS FOLLOW-UP`: 改善項目を追跡中
- `INVALID`: 同意・匿名化・手順に問題があり、その記録を改善根拠として使えない

問題の重大度は優先順位付けのために記録します。P0・P1が見つかったときは速やかに修正を検討しますが、過去の公開や教材完成を遡って不合格にはしません。

## STEP 1との境界

L12→L13の読込成功・品質検査・raw保全・未見表への転移は[STEP 1 Data Quality Gate](../step1-data-gate/README.md)、L16修了後の分析一周の独立転移は[STEP 1独立転移観察キット](../step1-transfer-gate/README.md)で、必要に応じて公開後に記録します。これらも公開条件ではなく、どの教材接続を改善するかを追跡するための記録です。
