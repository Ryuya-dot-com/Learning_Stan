# 04 尤度と応答分布

## この回のゴール

観測値の型・支持範囲・観測単位から尤度候補を選び、尤度を「固定したデータのもとでパラメータを比べる量」として説明できる。

## 前提

- Bernoulli試行、Binomial正答数、確率と観測割合を区別できる。
- 回帰の予測値が、観測値そのものではないと説明できる。

## 研究場面

同じ認知課題でも、記録する変数が変われば観測モデルも変わります。

| 記録したもの | 1行の例 | 値の範囲 | 最初の候補 |
|---|---:|---|---|
| 1試行の正誤 | 1 | 0または1 | Bernoulli |
| 1人の正答数 / 20問 | 16 | 0〜20の整数 | Binomial |
| 10分間の来室人数 | 3 | 0以上の整数 | Poisson |
| 参加者の平均反応時間 | 565 ms | 正の連続量 | Normalまたは正の歪みを許す候補 |

ここでの候補は自動的な正解ではありません。たとえば、人数が日によって大きく揺れるならPoissonの平均と分散が同程度という仮定は外れるかもしれません。反応時間が右に長い裾を持つなら、Normalだけでは不十分かもしれません。まず、何を一観測と数え、どんな値があり得るかを明示します。

## 尤度は何を比べるか

20問中16問正答という観測を考えます。正答確率を\(p\)とすると、Binomialモデルは

\[
K\mid p\sim\operatorname{Binomial}(20,p)
\]

です。観測した \(K=16\) を固定すると、尤度は

\[
L(p;y)=\Pr(K=16\mid p)
\]

と書けます。これは「各\(p\)のもとで、16正答がどれくらいもっともらしいか」を比べる関数です。\(p\)を確率変数として正規化したものではありません。

Rで格子状の\(p\)を比較します。

~~~r
correct <- 16
trials <- 20

p_grid <- seq(0.01, 0.99, by = 0.01)
likelihood <- dbinom(
  correct,
  size = trials,
  prob = p_grid
)

plot(
  p_grid,
  likelihood,
  type = "l",
  xlab = "正答確率 p",
  ylab = "16正答を得る尤度",
  main = "観測 16 / 20 に対するBinomial尤度"
)
abline(v = correct / trials, col = "firebrick", lty = 2)
~~~

曲線の高い場所は、16/20というデータにより整合的な\(p\)です。しかし、曲線の縦軸を足しても1にはなりません。尤度は \(p\) の確率分布ではないからです。次回、priorを掛けて全体を正規化するとposterior distributionになります。

## 生成過程・尤度・予測を分ける

同じモデルを三つの向きから読むと混同が減ります。

1. **生成過程**  
   ある\(p\)を仮定し、20回の試行を生成すると正答数\(K\)が生じる。

2. **尤度**  
   16正答を観測したあと、異なる\(p\)がその観測をどれだけよく説明するかを比べる。

3. **予測**  
   \(p\)についての不確実性を考慮して、次の20問の正答数をどの程度予測するかを問う。

この三つに同じBinomial分布が登場しても、固定しているものと変化させるものが違います。

## 応答分布を選ぶ最初の順序

分布名を先に選びません。次の順序でデータ契約を作ります。

1. **観測単位**：1試行、1人の集計、1日、1刺激など、尤度の一寄与は何か。
2. **支持範囲**：0/1、非負整数、正の連続量、実数など、あり得ない値を候補から除く。
3. **記録過程**：20問のうちの正答数か、同じ時間に起きた回数か、上限で打ち切られた時間か。
4. **条件付きの形**：平均、ばらつき、尾、zeroの多さ、群・時点による変化を予測と照合する。

この順序は、後でStanの data block、likelihood、posterior predictive checkへそのままつながります。コンパイルが通る型でも、観測過程を正しく表すとは限りません。

## 典型的な誤解

1. **尤度はparameterの確率分布だ。**  
   データを固定した尤度は、parameterについて正規化されていません。priorと組み合わせて正規化したものがposteriorです。

2. **観測割合をBernoulliに渡せばよい。**  
   Bernoulliの観測値は0または1です。16/20のように成功数と試行数をまとめたならBinomialの観測として表します。

3. **正の値ならすべてNormalでよい。**  
   Normal分布は負の値も許します。正の支持、歪み、測定下限・上限、外れ値を確認します。

4. **Poissonを使えば曝露量は不要だ。**  
   10分の来室数と60分の来室数を同じ機会として比べるのは不適切です。観測時間などの曝露量を記録します。

## 理解問題

### 1. 選択：Binomialのデータ

どのデータが一つのBinomial尤度に最も直接対応しますか。

- A. 参加者が20問中16問正答した。
- B. 参加者の正答割合が0.80だったが、問題数は不明である。
- C. 参加者の反応時間が560 msだった。
- D. 10分間に3人来室した。

**解答：A。** 成功数16と試行数20がそろっています。Bは試行数がないため標本変動を決められません。Cは連続時間、Dはカウントであり、別の観測過程です。

### 2. 出力予測：尤度の山

20問中16問正答したとき、Binomial尤度が最も高くなりやすい\(p\)はどのあたりですか。

- A. 0.00
- B. 0.20
- C. 0.80
- D. 1.00

**解答：C。** この単純なBinomial尤度は観測割合16/20付近で最大になります。これは\(p=0.80\)が確実に真という意味ではなく、他の\(p\)との相対比較です。

### 3. 記述：尤度とposterior

「尤度の曲線が高い\(p\)ほど、その\(p\)が真である確率が高い」と言い切れない理由を一文で説明してください。

**rubric：** 尤度はparameterについて正規化された確率分布ではないこと、またはpriorを加えたposteriorが必要なことを述べれば十分です。データが無意味だという必要はありません。

### 4. レビュー：割合だけを渡す

共同研究者は、20問中16問正答を次のように書きました。

~~~r
y <- 16 / 20
# Bernoulli likelihood with y
~~~

何が足りず、どの表現が候補になりますか。

**解答：** Bernoulliは0/1の一試行に対応するため、0.80を一つのBernoulli観測として渡せません。試行ごとの0/1行を20行残すか、成功数16と試行数20をBinomialとして使います。どちらが適切かは、試行ごとの予測子・順序・参加者構造を残す必要があるかで決めます。

### 5. 主張境界

尤度曲線だけから最も適切に言えることはどれですか。

- A. \(p=0.80\)が真である確率は100%である。
- B. 16/20という観測は、0.20より0.80付近の\(p\)のもとで相対的にもっともらしい。
- C. 学習法が因果的に正答率を上げた。
- D. 次の20問では必ず16問正答する。

**解答：B。** Aは尤度をposterior probabilityと混同しています。Cには比較群・割付などの設計根拠が、Dには将来結果の不確実性が欠けています。

## 4段階練習

1. **まねる**  
   correctを16、trialsを20にして尤度曲線を描きます。曲線の頂点が観測割合の近くになることを予想してから確認します。

2. **一つ変える**  
   correctだけを10に変えます。試行数は20のまま、尤度の山がどちらへ移るかを予想します。

3. **見ずに作る＋デバッグ**  
   pの格子、dbinom、プロットを白紙から書きます。意図的に correctを21へ変え、なぜそのデータが trials=20 のBinomial契約に反するかを説明して直します。

4. **未見転移**  
   図書館の来室人数を分析する場面で、観測単位、支持範囲、観測時間、Poissonの候補理由、Poissonだけでは足りないかもしれない兆候をモデルカードに書きます。

## 任意課題

一試行ずつの0/1データと、同じデータを16/20に集計した表を作ります。予測子が何もない場合には二つが同じ正答率情報を持つことを説明し、試行順序や問題難易度を調べたい場合には一行ずつの表を残すべき理由を説明してください。
