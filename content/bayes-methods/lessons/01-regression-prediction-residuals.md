# 01 回帰：係数・予測・残差

## この回のゴール

参加者ごとの睡眠時間と平均反応時間の表から、線形回帰モデルの係数・予測値・残差を区別し、データが支える範囲に限って説明できる。

## 前提

- CSVをRのデータフレームとして読み、列を指定できる。
- 平均と散布図が何を要約するかを説明できる。

## 研究場面

認知課題の参加者ごとに、前夜の睡眠時間と平均反応時間を記録したとします。研究チームは「睡眠時間が長い参加者ほど、この標本では反応時間が短い傾向にあるか」を記述したいと考えています。

ここでは一人につき一つの平均反応時間を使います。元の試行データを参加者ごとに平均した表なので、試行ごとのばらつきや参加者内の条件差はまだ表していません。それらは後で階層モデルで扱います。

| participant | sleep_h | mean_rt_ms |
|---|---:|---:|
| P01 | 5.5 | 612 |
| P02 | 6.0 | 598 |
| P03 | 6.5 | 581 |
| P04 | 7.0 | 567 |
| P05 | 7.5 | 553 |
| P06 | 8.0 | 548 |

## データ表から予測式へ

睡眠時間をそのまま使う代わりに、標本平均からの差へ直します。

\[
x_i=\mathrm{sleep\_h}_i-\overline{\mathrm{sleep\_h}}
\]

この中心化は、切片を「睡眠時間が標本平均の参加者の予測平均反応時間」と読めるようにします。各参加者の予測平均を

\[
\mu_i=\alpha+\beta x_i
\]

と置きます。ここで \(\alpha\) は中心化した睡眠時間が0のときの予測、\(\beta\) は睡眠時間が1時間長いときに予測平均がどれだけ変わるかです。反応時間がミリ秒なら、\(\beta\) の単位もミリ秒/時間です。

実際の平均反応時間 \(y_i\) は、予測式と完全には一致しません。差

\[
e_i=y_i-\widehat{\mu}_i
\]

を残差と呼びます。残差は「真の誤差を観測した値」ではなく、当てはめたモデルと観測値の差です。

線形回帰は、この例では残差の二乗和が小さくなる \(\alpha\) と \(\beta\) を選びます。後のベイズ回帰では、同じ予測式に観測分布と事前分布を加え、係数の不確実性全体を扱います。

## Rで予測値と残差を確かめる

~~~r
study <- data.frame(
  participant = paste0("P0", 1:6),
  sleep_h = c(5.5, 6.0, 6.5, 7.0, 7.5, 8.0),
  mean_rt_ms = c(612, 598, 581, 567, 553, 548)
)

study$sleep_c <- study$sleep_h - mean(study$sleep_h)

fit <- lm(mean_rt_ms ~ sleep_c, data = study)
coef(fit)

study$predicted_rt_ms <- fitted(fit)
study$residual_ms <- resid(fit)
study

new_people <- data.frame(
  sleep_c = c(6, 8) - mean(study$sleep_h)
)
predict(fit, newdata = new_people)
~~~

同じ行について、観測値は常に「予測値 + 残差」になります。

~~~r
all.equal(
  study$mean_rt_ms,
  study$predicted_rt_ms + study$residual_ms
)
~~~

この結果が TRUE でも、直線モデルが研究対象に正しい、睡眠が反応時間を因果的に変えた、別の集団にも同じ傾きが成り立つ、とは言えません。予測式は標本内の関係を要約する道具です。直線性、外れた点、残差の広がり、研究デザインは別に確認します。

## 典型的な誤解

1. **残差が小さい参加者ほど「誤差の少ない人」だ。**  
   残差はその人の測定精度ではなく、そのモデルからのずれです。

2. **切片は必ず実在する人の予測値だ。**  
   中心化しない睡眠時間0の切片は、この研究範囲の外にあるかもしれません。切片の解釈は予測子の原点に依存します。

3. **負の係数なら睡眠を増やせば必ず反応が速くなる。**  
   観察データの係数は関連を要約します。介入の因果効果には、割付や交絡など別の根拠が必要です。

4. **予測値は次の参加者の実測値そのものだ。**  
   予測平均と、新しい個人の観測値には異なる不確実性があります。

## 理解問題

### 1. 選択：残差はどれか

ある参加者の観測反応時間が600 ms、モデルの予測値が575 msでした。残差として正しいのはどれですか。

- A. 25 ms
- B. -25 ms
- C. 575 ms
- D. 600 / 575

**解答：A。** 残差は観測値 - 予測値なので \(600-575=25\) msです。Bは引く順序を逆にした誤り、Cは予測値との混同、Dはこの回で定義した残差ではありません。

### 2. 出力予測：足し戻し

次を実行したとき、どの関係が成り立ちますか。

~~~r
study$predicted_rt_ms + study$residual_ms
~~~

**解答：各行の mean_rt_ms と一致します。** fitted値とresid値は、当てはめた同じモデルに対して作られるためです。ただし丸めた表示値ではわずかな差が見えることがあります。

### 3. 記述：係数の単位

睡眠時間を時間、反応時間をmsで測ったとき、\(\beta=-12\) を一文で説明してください。

**rubric：** 「睡眠時間が1時間長い」という変化、「予測平均反応時間が12 ms小さい」という向きと単位、「このモデル・標本での関連」という限定があれば十分です。「睡眠を1時間増やすと必ず12 ms速くなる」と因果断定した回答は修正します。

### 4. レビュー：中心化を消したコード

共同研究者が次のコードを書き、「切片は睡眠0時間の参加者の通常の反応時間だから重要だ」と説明しました。

~~~r
lm(mean_rt_ms ~ sleep_h, data = study)
~~~

何を確認・修正しますか。

**解答：** まず睡眠0時間が研究対象とデータ範囲にあるかを確認します。この表では5.5〜8.0時間なので、0時間の切片は外挿で、通常の参加者の解釈には向きません。標本平均で中心化すれば、切片を平均的な睡眠時間での予測として読めます。中心化は予測直線そのものを変えません。

### 5. 主張境界

この回帰だけから書ける報告として最も適切なのはどれですか。

- A. 睡眠を増やす介入は反応時間を改善する。
- B. この標本では、睡眠時間が長い参加者ほど平均反応時間が短い関連が推定された。
- C. すべての成人で睡眠時間が反応時間を決める。
- D. 残差があるので回帰分析は失敗した。

**解答：B。** AとCは研究デザインを越えた因果・一般化の主張です。Dは、残差があることを直線モデルの通常の構成要素ではなく失敗と誤解しています。

## 4段階練習

1. **まねる**  
   上のコードを実行する前に、睡眠時間が平均より長いP06の sleep_c の符号と、予測反応時間の方向を予想します。実行後、予測値と残差を表で確認します。

2. **一つ変える**  
   `sleep_h`はそのままにして、反応時間だけをミリ秒から秒へ変換します。係数と残差の単位がどう変わるかを書いてから実行します。

3. **見ずに作る＋デバッグ**  
   完成例を閉じ、データフレーム、中心化列、lm、予測値、残差の順で自作します。意図的に新しい参加者の列名を sleep_hours として predict に渡し、出るエラーを「newdataの列名契約」と説明して直します。

4. **未見転移**  
   参加者ごとの一日のカフェイン摂取量と、持続注意得点の表を作ります。どちらを応答にするか、係数の単位、切片が読める原点、因果と呼べない理由を短いモデルカードに記します。

## 任意課題

散布図に回帰線を重ね、残差を縦線で表してください。そのうえで、直線から大きく離れた点を一つ見つけても直ちに削除しない理由を、測定ミス・特殊な参加者・非線形性という少なくとも三つの可能性に分けて書きます。
