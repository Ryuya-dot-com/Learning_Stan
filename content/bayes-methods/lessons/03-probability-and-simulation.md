# 03 確率とシミュレーション

## この回のゴール

二値の試行データについて、確率・観測割合・生成過程を区別し、Rで生成規則を一つ変えて結果の分布を検証できる。

## 前提

- データフレームの列を取り出し、平均や割合を計算できる。
- 乱数を使うコードは同じ結果を毎回返さないことを知っている。

## 研究場面

二つの学習方法のあとで、参加者が20問の知識テストを受けました。以下は参加者をまとめた説明用の集計です。

| method | trials | correct | observed_proportion |
|---|---:|---:|---:|
| standard | 20 | 13 | 0.65 |
| retrieval | 20 | 16 | 0.80 |

13/20や16/20は観測された割合です。一方、\(p\) は「同じ条件を同じように繰り返したとき、一問が正答になる確率」という生成過程のパラメータです。観測割合と\(p\)は同じ記号にせず、別のものとして扱います。

## データ表から生成過程へ

一問の結果を \(y_i\) とします。

\[
y_i =
\begin{cases}
1 & \text{正答}\\
0 & \text{誤答}
\end{cases}
\qquad
y_i\sim\operatorname{Bernoulli}(p)
\]

20問の正答数 \(K=\sum_i y_i\) は、同じ\(p\)で条件付き独立な試行と仮定すれば

\[
K\sim\operatorname{Binomial}(20,p)
\]

となります。これは「20問を必ず独立に扱ってよい」という事実ではありません。練習、疲労、参加者差、出題の難しさがあれば、この単純な生成過程は不十分かもしれません。まず仮定が何を生むかをシミュレーションで確かめます。

## Rで標本変動を見る

同じ真の確率を \(p=0.70\) と置いても、20問の観測割合は毎回同じになりません。

~~~r
set.seed(20260813)

p_correct <- 0.70
n_trial <- 20

one_person <- rbinom(1, size = n_trial, prob = p_correct)
one_person / n_trial

many_people <- rbinom(1000, size = n_trial, prob = p_correct)
many_proportions <- many_people / n_trial

mean(many_proportions)
sd(many_proportions)

hist(
  many_proportions,
  breaks = seq(-0.025, 1.025, by = 0.05),
  xlab = "20問中の正答割合",
  main = "p = 0.70 から生じる観測割合"
)
abline(v = p_correct, col = "firebrick", lwd = 2)
~~~

赤線は生成に使った\(p\)です。棒の広がりは、20問しか観測しないことによる標本変動です。試行数を200へ増やすと、割合は一般に0.70の近くへ集まります。

~~~r
many_proportions_200 <- rbinom(
  1000,
  size = 200,
  prob = p_correct
) / 200

sd(many_proportions_200)
~~~

ここでのシミュレーションは「現実の参加者が本当にBinomialから来た」という証明ではありません。仮定した生成過程なら、どの程度のばらつきが普通に起こるかを可視化する実験です。

## 典型的な誤解

1. **0.70を指定すれば、20問では必ず14問正答になる。**  
   0.70は一問ごとの確率です。正答数は確率的に変動します。

2. **観測割合13/20は真の確率が必ず0.65という意味だ。**  
   観測割合は一つの標本結果です。真の確率を推定するには、標本変動と後の事前情報を扱います。

3. **seedを固定すると現実のデータも同じになる。**  
   seedはRの疑似乱数を再現するための指定で、実世界を決定するものではありません。

4. **Binomialなら参加者内の試行は自動的に独立だ。**  
   条件付き独立はモデルの仮定です。試行順序や参加者差を無視してよいかは研究場面で判断します。

## 理解問題

### 1. 選択：確率と割合

20問中16問正答した参加者について、正しい説明はどれですか。

- A. この参加者の真の正答確率は厳密に0.80である。
- B. この参加者の観測割合は0.80であり、真の確率の候補を考える材料の一つである。
- C. 次の20問でも必ず16問正答する。
- D. Bernoulliモデルでは試行数を使わない。

**解答：B。** AとCは観測結果を未知の生成確率や未来の結果と同一視しています。Dは誤りで、20回のBernoulli試行を合計したものがBinomialの正答数です。

### 2. 出力予測：試行数を増やす

真の確率を0.70のまま、rbinomの size を20から200へ変えると、1000人分の観測割合の標準偏差は通常どうなりますか。

**解答：小さくなります。** 1人あたりの試行数が多いほど、観測割合の標本変動は一般に小さくなります。平均が毎回正確に0.70になるとは限りません。

### 3. 記述：生成過程

「各参加者は20問に答えるが、後半ほど疲れて正答しにくい」という状況で、一定の\(p\)を使うBinomialモデルの仮定として疑うべきことを書いてください。

**rubric：** 試行ごとの正答確率が一定という仮定、試行順序・疲労への依存、または条件付き独立のいずれかを具体的に指摘できれば十分です。「Binomialは使えない」とだけ書き、どの生成規則が問題かを示さない回答は補います。

### 4. レビュー：乱数の使い方

共同研究者は、次のコードを一度実行して14問正答だったため、「この学習法なら20問中14問正答する」と報告しました。

~~~r
rbinom(1, size = 20, prob = 0.70)
~~~

何が問題ですか。

**解答：** この出力は仮定した確率モデルからの一回の複製です。確率的な結果の一つであり、必ず起こる結果でも、研究データから確認された効果でもありません。多くの複製の分布、実データ、モデル仮定を分けて報告します。

### 5. 主張境界

シミュレーションの結果から言えることはどれですか。

- A. 実際の参加者はBinomial分布に従うと証明された。
- B. \(p=0.70\)、20試行という仮定の下で、観測割合がどの程度揺れ得るかを確認した。
- C. 20試行なら標本変動は存在しない。
- D. retrieval法の因果効果が確認された。

**解答：B。** シミュレーションは仮定の帰結を確認します。AとDには実データと研究デザインの根拠が、Cには確率的変動の理解が欠けています。

## 4段階練習

1. **まねる**  
   p_correctを0.70、試行数を20にしたコードを実行する前に、一人の観測割合が0.70と異なる理由を一文で予想します。ヒストグラムへ赤線を足して確かめます。

2. **一つ変える**  
   p_correctだけを0.50へ変更します。ヒストグラムの中心がどう動くかを予想し、試行数は20のまま比較します。

3. **見ずに作る＋デバッグ**  
   seed、確率、試行数、1000人分の正答数、割合、ヒストグラムを白紙から作ります。意図的に prob = 70 と書いて出るエラーを、確率の許容範囲0〜1の契約違反として直します。

4. **未見転移**  
   10分間の語彙テストについて、正答数ではなく「一日に来室する人数」を扱うなら、何が同じで何が変わるかを考えます。観測単位、支持範囲、候補分布、条件付き独立の仮定を表にします。

## 任意課題

二つの学習方法の真の正答確率を0.70と0.75に固定し、各群20人・各人20試行のデータを1000回シミュレートしてください。二群の観測割合の差をヒストグラムにし、「差が正なら学習法が必ず優れている」という結論がなぜ早すぎるかを説明します。
