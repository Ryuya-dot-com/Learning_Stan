# 研究質問から報告まで：参加者×刺激の実践演習

この演習で答える問いは、「条件BとAで正答率はどう異なり、まだ測定していない参加者・刺激へどこまで予測できるか」です。参加者が複数の刺激へ反応する研究では、試行が多くても参加者や刺激の種類が少ないことがあります。試行数だけを標本数とみなすと、一般化したい対象と利用している情報が食い違います。その違いを、同じ訓練データに対するモデル・予測・保留評価・報告で追います。

L1–L41は入門コアとして維持します。このパックはL30（群構造）、L32（観測過程）、L33（予測対象と実装検証）、L41（分析完結）を接続する実践層です。合成データなので、得られた条件差を実在する実験の証拠として報告しません。

## 入口と到達点

| 今できること | 確認する課題 | 迷った場合に戻る教材 | このパックでの到達点 |
|---|---|---|---|
| R未経験 | CSVの1行と列の意味を説明し、条件別に数える | L1–L20 | 基礎を終えてから研究ケースへ |
| Rで集計・回帰ができる | 線形予測子、尤度、条件付き比較の違いを説明する | L21–L26 | brmsによる分析と限界付き報告 |
| brmsを使える | R-hat、PPC、予測対象を別の問いとして説明する | L29–L33 | 分割・予測・感度分析を自分で設計 |
| Stanへ進みたい | 同じpriorが同じ切片に置かれているか点検する | L34–L40 | 手書きStanとの対応検証とL41の提出 |

brmsで完結する提出は`run.R`と報告までです。手書きStanを検証する提出では`equivalence.R`と同値性の根拠も加えます。Stanを自作しない学習者にも前者の到達点があります。

## 新しいRセッションから実行する

ZIPを展開した`research-case`をRStudio Projectのルートにします。L26でR、brms、CmdStanR、CmdStanを用意しておきます。追加するRパッケージはbrms・cmdstanr・posterior・ggplot2です。通常実行は4 chains、各2000 iterations（前半1000はwarmup）です。測定誤差の積分モデルと詳細な感度分析では、各2000 warmup＋4000 samplingを使います。

```sh
Rscript --vanilla run.R
Rscript --vanilla equivalence.R
Rscript --vanilla identifiability.R
Rscript --vanilla observation.R
Rscript --vanilla measurement-sensitivity.R
# 計算量の大きい、固定真値の研究設計シミュレーション
Rscript --vanilla design.R
```

`run.R`だけで中心ケースは完走します。残りは問いごとに選ぶ比較演習です。`--smoke`を付けると2 chains・400 iterationsに短縮しますが、**これはファイル生成・コード接続の確認専用**です。推定精度、coverage、モデルの優劣の証拠には使いません。

各入口は`outputs/<演習名>`へ保存します。以前の結果があると停止します。再実行では、Rを起動する前に`LEARNING_STAN_OUTPUT`へ新しい保存先を設定します。CmdStanの場所が既定と違う場合は`LEARNING_STAN_CMDSTAN`を設定します。具体的な基準環境と復元範囲は同梱の`environment.md`を参照してください。

## 中心ケース：問い→調べ方→結果→答え

### 1. 何を比較するのか

24参加者×16刺激×2回の反応を生成します。条件は数値でA=-0.5、B=+0.5です。各参加者・刺激が両条件を経験する交差配置で、同じ刺激への反復には学習・持越し効果がないと仮定します。正誤は0/1であり、ここでは正答試行だけを選別しません。

生成モデルは

$$
y_{pir}\sim\operatorname{Bernoulli}(p_{pir}),\qquad
\operatorname{logit}(p_{pir})=\alpha+\beta x_{pir}+a_p+b_i.
$$

母数はα=0.4、β=0.6、参加者SD=0.7、刺激SD=0.5です。βは群効果で条件付けた**対数オッズ差**です。「正答率が0.6高い」ではありません。確率差を答えにするなら、誰・何について平均するかを先に定義し、その対象への予測確率の差を使います。

### 2. なぜこの3モデルを比べるのか

| モデル | 式の追加部分 | 確かめること | 仮定と限界 |
|---|---|---|---|
| 試行独立 | なし | 群を省いた分析の区間と予測 | 残った依存を扱わない比較用 |
| 参加者差 | `(1 | participant)` | 同じ人の情報を利用する効果 | 刺激差は表さない |
| 参加者×刺激 | 両方のrandom intercept | 一般化対象が二つあるときの予測 | 傾きは一定、群効果は正規分布 |

全モデルの訓練行は同じです。ただしロジスティックモデルでは、群効果に条件付けるかによって係数の意味も異なります。係数の差をすべて「省略による偏り」と呼びません。主要な比較は同じ保留データへの予測で行います。個人別条件差を知りたい場合はvarying slopeとそれを支える設計が別に必要です。

### 3. 何を保留し、何を予測するのか

| 予測対象 | 訓練に使える群情報 | 検証データの作り方 |
|---|---|---|
| 既存参加者×既存刺激 | 両方の観測済み効果 | 一部の再測定だけ保留 |
| 新参加者×既存刺激 | 刺激の効果だけ | その参加者の全反応を訓練から外す |
| 既存参加者×新刺激 | 参加者の効果だけ | その刺激の全反応を訓練から外す |
| 新参加者×新刺激 | 両方とも未観測 | 保留参加者と保留刺激を訓練のどの行にも含めない |

`split_trials()`で群の最後の約20%を保留し、残る群の一部の2回目反応も保留します。ひとつの共通訓練集合から4対象を評価できる設計です。これは**単一の保留評価**であり、反復交差検証を実施したことにはなりません。

`allow_new_levels=TRUE, sample_new_levels="gaussian"`は、未観測の群の効果を、推定した群分布からdrawごとに生成します。同じ新IDの複数行は同じ効果を共有します。`re_formula=NA`で群効果を0にする予測は、群の不確実性を積分した新対象予測と同じではありません。

### 4. 推定前後で何を点検するのか

`raw-trials.csv`から行ID、欠測、値域、条件別・群別件数を確認し、`analysis.csv`で実際に使った訓練行を固定します。`prior-predictive.png`は事前分布から得る全体正答率です。極端な正答率を許す幅が研究に適切かを、事後分布を見る前に判断します。この合成例では広い分布を意図しています。

通常実行では全モデルでR-hat<1.01、bulk/tail ESS≥400、divergence=0、最大tree depth到達=0、chain別E-BFMI≥0.3を満たさなければ停止します。これはこの教材の停止規則で、十分条件でも万能な数値基準でもありません。停止したら保存済み診断を読み、理由を記録して別runへ進みます。MCMCが通ってもPPCに問題があれば研究上の結論を保留します。

`item-ppc.png`は刺激別の平均正答率の再現を見ます。二値データの全体平均だけではモデル批判として弱いため、参加者別の分散や条件差の再現も学習者が追加する候補です。`prior-sensitivity.csv`では条件係数のpriorだけをN(0,1)からN(0,0.5)へ変更します。

### 5. 数字から答えを書く

| 成果物 | 答える問い | 報告上の注意 |
|---|---|---|
| `condition-effects.csv` | 条件差の方向・大きさ・90%区間 | 対数オッズ尺度、群構造を併記 |
| `holdout-scores.csv` | 対象別に予測がどれだけ外れたか | Brierは小さい方、log scoreは大きい方。対象を混ぜて順位付けしない |
| `predictive-intervals.csv` | 集団の期待正答率と、新たに観測する集団正答率の幅 | 両方とも群効果の不確実性を含む。後者には二値反応の揺れも含む |
| `*-probabilities.csv` | どの保留行をどう予測したか | 1反応の予測区間はしばしば[0,1]。期待確率の区間と混同しない |
| `*-diagnostics.csv`ほか | 解釈を開始できる計算状態か | 良い診断は識別・観測過程・因果性の保証ではない |

log scoreは各反応の**周辺予測確率**の対数を平均した値です。群内依存を積分した集団全体の同時確率ではありません。単一分割なのでモデル差の安定性や比較差の標準誤差は評価していません。

`analysis-record.md`は実行記録です。提出する答えは`starter/report.md`へ、少なくとも「問い・方法を選んだ理由・方向と大きさ・診断/PPC・どの対象に限るか・言えないこと」を書きます。自動生成ファイルだけで学習者の解釈が完了したとは判定しません。

## 比較演習

### 識別可能性：事後分布が得られることとデータから分かること

`identifiability.R`はα+βだけが尤度に入る正規モデルを解析的に計算します。αのpriorを変えるとαとβの配分が変わる一方、和は比較的安定します。MCMCを使わずにこの差を確認するので、良いR-hatで問題が解消するという誤解を避けられます。

さらに、条件が参加者または刺激ごとに固定された配置の固定効果設計行列を比較します。rank不足は「無制約の個体別切片と条件効果を分離できない」ことを示します。**無作為化された参加者間実験でも母集団効果が一切推定できない、という意味ではありません。** 母集団比較には割付けと交換可能性の仮定があり、個人内効果の識別とは分けます。1試行だけでは個人の切片と傾きを同時に学習できず、階層モデルの事後分布は全体分布・priorに依存します。

### brmsとStan：どこまで同じか

`equivalence.R`は中心ケースの**試行独立モデル**を手書きStanと比較します。交差モデルの手書き実装まで検証済みとは扱いません。

| 研究上の意味 | brms | 手書きStan |
|---|---|---|
| 条件と正誤 | 同じ訓練行の`x`, `correct` | 同じ`x`, `y` |
| 切片 | `0 + Intercept`の`b_Intercept` | `alpha` |
| 切片prior | class b, coef Intercept, N(0,1.5) | `alpha ~ normal(0,1.5)` |
| 条件効果 | `b_x`, N(0,1) | `beta`, N(0,1) |
| 観測モデル | Bernoulli(logit) | `bernoulli_logit` |
| 期待値・複製反応 | epred / predict | `p` / `y_rep` |

通常のbrms切片は内部中心化した切片にpriorを置くので、ここでは明示的な切片で揃えます。期待確率の差をchain構造を保持したMCSEから比較します。4×合成MCSEは数値的な照合の目安で、同値性の数学的証明ではありません。証明の根拠は、同じ行・尺度・尤度・prior・予測対象を使う対応表です。二値反応1個の事後予測分布は成功確率E[p]で定まるため、期待値の比較と複製反応の割合の双方を保存します。

### 観測過程：タイムアウトと測定誤差

`observation.R`の前半は、全反応の潜在時間をlognormalから生成し、800msの締切を設けます。「締切までに反応しなかった」行を削除する分析、800msの正確な観測として扱う分析、800ms以上とする右打ち切り分析を比較します。正答試行だけのRTという別の対象ではありません。削除分析は締切前に完了した反応へ対象を変え、代入は観測事実と異なる尤度を使います。打ち切りモデルも潜在時間分布と締切機構への仮定に依存します。

後半は真の説明変数に測定誤差を加え、誤差無視と測定誤差を表すモデルを比較します。測定誤差SD=0.7は外部情報として与え、0.75倍・1倍・1.25倍を比較します。1回の誤差を含む測定だけから誤差分散まで自由に識別できるとは仮定しません。`MEASUREMENT_SCALES`で比較範囲を変更できます。

初版のbrms `mi()`による1.25倍条件は診断停止しました。現在は正規の潜在変数を積分消去した同じ尤度・priorのStan実装を使い、1.25倍でも診断を通過しています。[詳細な感度分析](measurement-sensitivity.md)ではSDの6条件とpriorの8条件、brmsとの照合、独立seedでの再実行を確認しました。方向は正のままでも、SDを1倍から1.25倍にすると係数平均が約40%変わり、**大きさの頑健性を確認した結果ではありません**。基準の1倍が失敗すれば停止し、他の診断失敗も推定値NA・`INCOMPLETE_SENSITIVITY`として残す方針は維持します。外部SD・正規潜在分布・独立誤差の仮定とともに解釈してください。

### 研究設計：何の性能を測っているか

`design.R`は参加者数・刺激数・反復数・欠測/不均衡を変えます。真値β=0.6を固定し、群効果とデータを反復生成します。出力は偏り、90%区間の幅・coverage、反復間MCSE、失敗数です。失敗runを黙って削除せず、成功run条件付き集計であることを示します。通常50反復は演習用の出発点で、必要精度を保証しません。`DESIGN_REPS`で増やし、coverageの二項区間も確認してください。

これは固定真値の設計検討です。SBCなら各反復で母数をpriorから引き、事後順位を調べます。自己相関を無視した順位は不適切になり得ます。どちらも現実の観測過程が正しいことを保証しません。

## L41の配布物と修了判定

- 最小の正しい参照分析：`run.R`と必要な補助ファイル。診断・PPC・保留分割を追跡できます。
- もっともらしい誤り：`candidate.R`。新参加者予測の意味と区間の意味をレビューします。
- 学習者が完成させる分析：`starter/analysis.R`、`protocol.md`、`report.md`。空欄を埋め、採否の理由を残します。
- 独立転移：`transfer.R`で別の合成データを生成し、`starter/transfer.md`に従って予測対象と欠測への判断を変更します。

修了は見本に近い係数を出すことではありません。第三者が①何を分析したか、②何を推定したか、③どの点検で止めた/進めたか、④どの対象に何を主張したか、⑤どこまで自力だったかを追えることを確認します。初回・修正版を分け、第三者が新しいセッションから再実行した結果を報告へ添えます。

保持・転移の受講者観察は既存の観察手順を利用し、自力・公式資料参照・他者支援を区別します。コード検証の成功を学習効果の確認済みとは扱いません。
