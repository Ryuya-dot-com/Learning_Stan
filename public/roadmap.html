L36

生成過程を対数密度へ翻訳する

単回帰を、未知量、事前分布、尤度へ分解します。sampling statementの~は乱数代入ではなく、現在値の対数密度をtargetへ加える記法として理解します。

Stan
model {
  alpha ~ normal(0, 2);        // 事前分布
  beta  ~ normal(0, 1);
  sigma ~ exponential(1);
  y ~ normal(mu, sigma);             // 尤度
}

※ stancode(fit)でbrms生成コードと照合し、式・生成過程・Stanコードの3表現を往復します。

ブリッジ / 頻度主義との橋渡し

2つの統計の言葉を話す 卒論・共同研究のための現実解

研究室の外ではまだ頻度主義が主流。どのレッスンの後からでも合流できる独立トラックで、両方の言葉を行き来できるようにします。

対応

t検定 vs ベイズ推定

同じデータに t.test と brm を当て、信頼区間と信用区間、p値とpdを並べて見る。「結論はだいたい一致するが、言えることが違う」を体感します。

t.testbrmpd_to_p
対応

lme4 vs brms

同じ式 (1|subj) がそのまま動く2つの世界。頻度主義GLMMの定番lme4と結果を突き合わせ、収束に悩んだときの選択肢としてのベイズを知ります。

lmerbrm(1|subj)
