L23 モンテカルロ・シミュレーション

「n=20・効果量 d=0.5 の実験、何%有意になる?」——1万回の仮想実験で検定力分析を自作します。この「生成→検定→集計」の型が、ベイズ編の「生成→推定→復元」につながる背骨です。

R
power_sim <- function(n, d, nsim = 10000) {
  hits <- replicate(nsim, {
    a <- rnorm(n)              # 統制群
    b <- rnorm(n) + d          # 実験群(効果量 d)
    t.test(a, b, var.equal = TRUE)$p.value < 0.05
  })
  100 * mean(hits)
}

set.seed(2026)                   # 再現性の確保
cat("検定力:", power_sim(20, 0.5), "%\n")
▶ 実行結果(R 4.6)検定力: 32.98 %

※ 理論値は power.t.test で 33.77%(実測)。乱数の結果はシードやバージョンによりわずかに変わります。関数に包んでおけば、n や d を変えて何度でも呼べます。

生成過程を対数密度へ翻訳する

単回帰を、未知量、事前分布、尤度へ分解します。sampling statementの~は乱数代入ではなく、現在値の対数密度をtargetへ加える記法として理解します。

Stan
model {
  alpha ~ normal(0, 2);        // 事前分布
  beta  ~ normal(0, 1);
  sigma ~ exponential(1);
  y ~ normal(mu, sigma);             // 尤度
}

※ stancode(fit)でbrms生成コードと照合し、式・生成過程・Stanコードの3表現を往復します。
